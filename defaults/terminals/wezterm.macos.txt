# name: WezTerm
# source: https://wezterm.org/config/default-keys.html
⌘T|new tab
⌘⇧[ ⌘⇧]|prev / next tab
⌘1..9|go to tab (9 = last)
⌃⌥⇧%|split right
⌃⌥⇧"|split down
⌃⇧←→↑↓|move between panes
⌃⌥⇧←→↑↓|resize pane
⌃⇧Z|zoom pane
⌘W|close tab
⌘F|find
⌘K|clear scrollback
⌘= ⌘- ⌘0|font size
⌘R|reload config
⌃⇧P|command palette
⌃⇧Space|quick select
⌃⇧X|copy mode
