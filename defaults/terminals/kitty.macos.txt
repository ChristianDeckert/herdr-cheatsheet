# name: kitty
# source: https://sw.kovidgoyal.net/kitty/conf/#keyboard-shortcuts
## tabs
⌘T|new tab
⌘⇧[ ⌘⇧]|prev / next tab
⌘W|close tab
## panes
⌘↩|new window (split)
⌃⇧[ ⌃⇧]|prev / next window
⌘1..9|go to window N
⌃⇧L|next layout
⌘⇧D|close window
## text
⌘F|search scrollback
⌘⌥K|clear scrollback
⌃⇧E|open URL (hints)
⌃⇧H|browse scrollback
## app
⌘+ ⌘- ⌘0|font size
⌘,|edit config
⌃⌘,|reload config
⌃⇧F3|command palette
