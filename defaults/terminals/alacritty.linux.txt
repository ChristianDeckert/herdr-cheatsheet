# name: Alacritty
# source: https://alacritty.org/config-alacritty-bindings.html
## text
Ctrl+Shift+C|copy
Ctrl+Shift+V|paste
Shift+Insert|paste selection
Ctrl+Shift+F|search forward
Ctrl+Shift+B|search backward
Shift+PgUp / PgDn|scroll page up / down
Shift+Home / End|scroll to top / bottom
Ctrl+L|clear screen
Ctrl+Shift+Space|toggle vi mode
v / y|vi: select / copy
/ ?|vi: search fwd / back
i|vi: exit vi mode
## app
Ctrl+= / Ctrl+-|font bigger / smaller
Ctrl+0|reset font size
