## text
Ctrl+Shift+C / V|copy / paste
select / mid-click|copy / paste primary selection
Shift+Insert|paste primary selection
Ctrl+Shift+F / B|search forward / backward
(Shift+)Enter|search: next (prev) match
Esc|search: cancel
Shift+PgUp / PgDn|scroll page up / down
Shift+Home / End|scroll to top / bottom
Ctrl+Shift+O|URL hints (type label to open)
click URL|open URL (Shift in mouse apps)
Ctrl+Shift+Space|toggle vi mode
v / V / Ctrl+V|vi: select char / line / block
y|vi: copy selection
/ ? n N|vi: search fwd/back, next/prev
Enter|vi: open URL under cursor
i / Ctrl+C|vi: exit vi mode
## app
Ctrl++ / - / 0|font bigger / smaller / reset
