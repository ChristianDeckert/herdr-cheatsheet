## tabs
⌘N|new window
⌘T|new tab
⌘⇧[ ⌘⇧]|prev / next tab
⌘1 … ⌘9|go to tab (⌘9 = last)
⌘W|close window / tab
## text
⌘C ⌘V|copy / paste
⌘F ⌘B|search forward / back
↩ ⇧↩|search: next / prev match
⎋|search: cancel
⌘K|clear screen & scrollback
⇧PgUp ⇧PgDn|scroll page up / down
⇧Home ⇧End|scroll to top / bottom
⌃⇧O|URL hints (type label to open)
⌃⇧Space|toggle vi mode
v ⇧V ⌃V|vi: select char / line / block
y|vi: copy selection
i ⌃C|vi: exit vi mode
## app
⌘+ ⌘- ⌘0|font bigger / smaller / reset
⌘⌃F|toggle fullscreen
