# name: Alacritty
# source: https://alacritty.org/config-alacritty-bindings.html
## tabs
⌘N|new window
⌘T|new tab (native)
⌘⇧[ ⌘⇧]|prev / next tab
⌘1 … ⌘9|go to tab (⌘9 = last)
## text
⌘C ⌘V|copy / paste
⌘F ⌘B|search forward / back
⌘K|clear screen & scrollback
⇧PgUp ⇧PgDn|scroll page up / down
⇧Home ⇧End|scroll to top / bottom
⌃⇧Space|toggle vi mode
v y|vi: select / copy
/ ?|vi: search fwd / back
## app
⌘+ ⌘- ⌘0|font size
⌘⌃F|toggle fullscreen
