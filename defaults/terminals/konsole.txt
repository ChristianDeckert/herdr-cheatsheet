# name: Konsole
# source: https://docs.kde.org/stable_kf6/en/konsole/konsole/commandreference.html ; https://invent.kde.org/utilities/konsole/-/blob/release/25.08/src/ViewManager.cpp ; https://invent.kde.org/utilities/konsole/-/blob/release/25.08/src/session/SessionController.cpp ; https://invent.kde.org/utilities/konsole/-/blob/release/25.08/src/MainWindow.cpp ; https://invent.kde.org/utilities/konsole/-/blob/release/25.08/data/keyboard-layouts/default.keytab
## tabs
Ctrl+Shift+T|new tab
Ctrl+Shift+W|close session (tab / view)
Shift+← / →|prev / next tab
Alt+1..9 / Alt+0|go to tab 1–9 / 10
Ctrl+Alt+← / →|move tab left / right
Ctrl+Alt+S|rename / configure tab
## panes
Ctrl+( / Ctrl+)|split left-right / top-bottom
Ctrl+Shift+←→↑↓|focus view in direction
Ctrl+Shift+[ / ]|shrink / expand view
Ctrl+Shift+E|toggle maximize view
Ctrl+Shift+H|detach view to new window
## text
Ctrl+Shift+C / V|copy / paste
Ctrl+Shift+F|find
F3 / Shift+F3|find next / previous
Shift+PgUp / PgDn|scroll page up / down
Ctrl+Shift+PgUp/Dn|prev / next prompt
Ctrl+Shift+K|clear scrollback & reset
Ctrl+Shift+D|keyboard select mode
Ctrl+Shift+A / I|monitor activity / silence
## app
Ctrl+Shift+N|new window
Ctrl++ / Ctrl+-|font bigger / smaller
Ctrl+Alt+0|reset font size
F11|fullscreen
Ctrl+Shift+,|configure Konsole
