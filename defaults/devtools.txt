## ios @macos
xcodebuild -list|list schemes and targets
xcodebuild -scheme {scheme} -destination 'platform=iOS Simulator,name={device}' build|build for simulator
xcodebuild -scheme {scheme} -destination 'platform=iOS Simulator,name={device}' test|run tests on simulator
xcodebuild -scheme {scheme} clean|clean build products
xcrun simctl list devices available|available simulators
xcrun simctl boot {udid}|boot a simulator
xcrun simctl install booted {app}|install app on booted sim
xcrun simctl launch booted {bundle_id}|launch app on booted sim
open -a Simulator|open simulator app
swift build|build swift package
swift test|run package tests
swift package resolve|resolve package deps
swift package update|update package deps
pod install|install cocoapods deps
pod update|update cocoapods deps
pod repo update|update pod spec repos
xcode-select -p|active developer dir
## android
./gradlew assembleDebug|build debug apk
./gradlew installDebug|build and install debug
./gradlew test|run local unit tests
./gradlew clean|clean build outputs
./gradlew lint|run android lint
./gradlew tasks|list gradle tasks
adb devices|list connected devices
adb install -r {apk}|reinstall apk keeping data
adb logcat|stream device log
adb shell|interactive device shell
adb reverse tcp:{port} tcp:{port}|forward device port to host
emulator -list-avds|list virtual devices
emulator -avd {name}|start emulator
sdkmanager --list|list sdk packages
## flutter
flutter doctor|check toolchain and devices
flutter create {name}|new flutter project
flutter pub get|get dependencies
flutter pub add {package}|add a dependency
flutter pub outdated|show outdated dependencies
flutter devices|list connected devices
flutter emulators --launch {emulator}|start an emulator
flutter run|run app (r reload, R restart)
flutter run -d {device}|run on a specific device
flutter test|run tests
flutter analyze|analyze the project
dart format .|format dart code
dart fix --apply|apply automated fixes
flutter build apk --release|build release apk
flutter build appbundle|build android app bundle
flutter build ipa|build ios archive (macOS)
flutter build web|build web app
flutter clean|delete build outputs
flutter upgrade|upgrade the flutter sdk
## python
python3 -m venv .venv|create virtual env in .venv
source .venv/bin/activate|activate venv (bash/zsh)
python3 -m pip install -r requirements.txt|install from requirements
python3 -m pip install {package}|install a package
python3 -m pytest|run tests with pytest
uv sync|sync project env (uv)
uv run {script}|run script in uv env

## node

## docker

docker run --rm -it {image}|run interactive, auto-remove
docker ps|list running containers
docker logs -f {container}|follow container logs
docker exec -it {container} sh|shell into container
docker compose up -d|start services detached
docker compose down|stop and remove services
