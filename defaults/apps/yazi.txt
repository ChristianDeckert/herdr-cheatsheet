# name: yazi
# source: https://github.com/sxyazi/yazi/blob/shipped/yazi-config/preset/keymap-default.toml
## navigate
j / k|next / previous file
h / l|parent / enter dir
gg / G|top / bottom
Ctrl+U / Ctrl+D|half page up / down
z / Z|jump via fzf / zoxide
## files
Space|toggle selection
v|visual mode
y / x|yank (copy) / cut
p / P|paste / paste overwrite
d / D|trash / delete permanently
a / r|create / rename
## view
.|toggle hidden files
/ / ?|find next / previous
s / S|search by name / content
## app
tt|new tab
[ / ]|previous / next tab
~ / F1|help
q|quit
